04 · DB: 決めたこと

要求は消さない・閉じない。色は保存せず、つながりから計算する

1
アーカイブだけ
DELETE は archived_at を入れる。活動をアーカイブすると手順も。マップ・抜け・つながりの一覧から消える
2
キーは使い回さない
req_counters で採番。TAPP-ST2 をアーカイブしても次は TAPP-ST3。手順は活動ごとの連番
3
イシューは同じプロジェクトだけ
別プロジェクトのイシューをつなごうとすると 400。PUT は何度呼んでも同じ（履歴も 1 回）
1
カードの色（status）
条件なし = draft、条件あり・作業前 = ready、イシューが進行中 = in_progress、すべて完了/キャンセル（1 件以上完了）= done
2
履歴が版の代わり
作成・変更（変えた項目）・アーカイブ・つなぐ/外す。ストーリー詳細に新しい順で 50 件
3
受入基準とは別物
イシューの acceptance_criteria は今のまま。「写す」ボタンで【前提】【操作】【結果】の 1 行にして足す。同期はしない
