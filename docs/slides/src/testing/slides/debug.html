03 · 失敗したとき

スクリーンショットとトレースで、そのときの画面を見る

やりたいことコマンド（e2e/ の中で）
失敗の一覧と画面・トレースpnpm exec playwright show-report
1 件のトレース（操作ごとの画面・DOM・通信）pnpm exec playwright show-trace test-results/…/trace.zip
ブラウザを表示しながらpnpm exec playwright test --headed
1 ステップずつ止めながらpnpm exec playwright test --debug -g "名前"
不安定なテストを探すpnpm exec playwright test --repeat-each=5

失敗したテストの記録は e2e/test-results/ に残る（git には入らない）
