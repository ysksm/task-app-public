02 · 流し方

make で流す。一部だけなら各ディレクトリで

$ make test       # 単体 + API（10 秒ほど）
$ make test-e2e   # 画面（Web UI ごとビルド）

# 初回だけ: ブラウザを入れる
$ cd e2e && pnpm exec playwright install chromium

# 一部だけ
$ cd e2e && pnpm exec playwright test tests/map.spec.ts
$ cd e2e && pnpm exec playwright test -g "drag"

# 別の実装を確かめる
$ make test-e2e TASKAPP_BIN=/path/to/taskapp

前提

Go 1.24+、Node 22+、pnpm。最初に pnpm install

並列に流れる

テストごとに demo データ入りのサーバーを空きポートで起動するので、互いに影響しない

3 / 6
