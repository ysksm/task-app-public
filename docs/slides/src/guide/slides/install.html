01 · インストール

単一バイナリを置いて起動するだけ

$ taskapp serve
# → http://127.0.0.1:7700
#   この PC のブラウザはログインなし
#   既定は 127.0.0.1 だけで待ち受け

# デモデータで試す
$ taskapp seed --preset demo --data /tmp/demo
$ taskapp serve --data /tmp/demo

配布物

macOS / Linux / Windows（amd64・arm64）のアーカイブ。Web UI も中に入っている

データ

~/.taskapp/taskapp.db（SQLite）。--data か TASKAPP_DATA で変更
