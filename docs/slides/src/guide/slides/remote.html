08 · ほかの端末から使う

--host で開き、ほかの端末はパスワードでログイン

# 1. 外から接続できるように起動
$ taskapp serve --host 0.0.0.0
# 2. パスワードを設定（設定 › アカウントでも可）
$ taskapp passwd --user kasa
# 3. スマホ・別の PC で開いてログイン
#    http://192.168.1.10:7700
# 4. 別の PC のエージェント（MCP HTTP）
$ claude mcp add --transport http taskapp \
    http://192.168.1.10:7700/mcp \
    --header "Authorization: Bearer <トークン>"

パスワードの設定

自分: 設定 › アカウント。ほかの人: オーナーがメンバー一覧から。コマンド: taskapp passwd

暗号化されない

自宅・社内の LAN か Tailscale などの VPN の中だけで。パスワードなしで入れるのはこの PC だけ
