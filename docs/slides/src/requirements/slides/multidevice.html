13 · 複数端末からの利用（§4.12）

スマホや別の PC からも、ログインして使う

ID要求
MD-01--host で外部から接続できるアドレスで待ち受けられる。既定は 127.0.0.1 のまま
MD-02ログイン画面。人間はユーザー名 + パスワード、エージェントはトークンだけ
MD-03パスワードは設定画面と taskapp passwd で設定。8 文字以上、ハッシュで保存し API・エクスポートに出さない
MD-04ログインはサーバーが動いている間だけ有効。ログアウトできる
MD-05パスワードなしの自動ログインは、この PC（接続元と Host がループバック）からだけ
MD-06外部向けで起動したら、暗号化されないことを警告。保護は VPN（Tailscale など）に任せる
MD-07MCP（HTTP）と Jira 互換 API はほかの端末からもトークンで。設定画面に URL を出す
MD-08（S）パスワードの総当たりを遅らせる（続けて失敗したら一時的に断る）
MD-09（S）同じマシンのリバースプロキシ（tailscale serve など）の後ろで動かせる。MCP はプロキシの Host を受け、自動ログインは止める
