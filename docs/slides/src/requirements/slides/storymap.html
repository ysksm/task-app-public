13 · 要求の層（ストーリーマップ・§4.13）

誰が・どんな場面で・何のために、をイシューとつなぐ

ペルソナとジョブ（REQ-01）

人 / AI のペルソナ。ジョブは「状況・したいこと・そうすれば」で書き、活動につなぐ

ストーリーマップ（REQ-02, 05）

活動と手順を横、リリースを縦。手順の下にストーリー。手順のないストーリーなどの抜けを一覧

受け入れ条件とイシュー（REQ-03, 04, 08）

Given / When / Then。同じプロジェクトのイシューをつなぎ、カードの色はその状態から。受入基準へ写せる

閉じない・使い回さない（REQ-06, 07）

削除はアーカイブ、キー（TAPP-ST12 など）は使い回さない。変更履歴。イシュー詳細と MCP に「なぜ」
