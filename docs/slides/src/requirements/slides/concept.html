内部は Linear ライク、外部は Jira 互換と MCP

Linear ライク UI

シンプルなステータスと階層データ。キーボード中心で速く操作できる

人間: PM・QA・受入検査

Jira 互換 API (v3)

REST API v3 互換。ORCA の Jira 連携（Cloud モード）からそのまま接続できる

ORCA: タスク取得・更新

MCP サーバー

エージェントがチェックポイント記録や QA 起票をツールとして呼べる

エージェント: 記録・質問

手元の PC で動く単一バイナリ（ほかの端末からも接続可）。UI・API・MCP は同じサービス層を通る
