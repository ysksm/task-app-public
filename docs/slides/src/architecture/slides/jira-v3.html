11 · Jira 互換レイヤー（REST API v3）

v3 固有の対応: ADF・accountId・新しい検索

項目v3 での扱い
説明・コメントADF（JSON の文書ツリー）。内部は Markdown のまま保存し、internal/jira/adf で相互変換
ユーザーaccountId = 内部ユーザー ID。accountType は人間 atlassian / エージェント app
検索POST/GET /search/jql。nextPageToken と isLast でページング
プロジェクトGET /project/search（startAt / maxResults / isLast / values）
認証Basic（メール + API トークン）。ORCA の Cloud モードはこの方式のみ。失敗は必ず 401
ID・応答id は数値（jira_id）。更新・遷移は 204 本文なし。JQL エラーは「Error in the JQL Query」

ORCA は Cloud モードでも接続先 URL を限定しないため、http://127.0.0.1:7700 をそのまま登録できる
