チェックポイント・QA・受入の持ち方

チェックポイント = 専用テーブル

判断基準・確信度・進捗率などの構造化項目を持ち、活動フィードや「確信度低」で横断検索する。Jira API からは [Checkpoint] 付きコメントとして見せる

QA = 種別 + 拡張テーブル

担当・ステータス・コメント・ORCA での表示などチケットの機能をそのまま使う。背景・暫定判断・ブロッキングは 1:1 の qa_details、質問と回答は 1:N の qa_items に持つ

受入 = ステータス + 記録

「受入待ち」は started カテゴリのステータス（ボードの1列）。基準は acceptance_criteria、判定は acceptance_reviews と基準ごとの結果に残す
