12 · テスト戦略

同じ API テストが通れば、Rust 版でも同じ振る舞い

API テスト（主）

apitest/ · TypeScript + Vitest。$TASKAPP_BIN を起動して /api/v1・Jira 互換・MCP を叩く。Rust 版にもそのまま使える

単体テスト

Go testing。階層規則・JQL パーサ・Filter → SQL。実装と一緒に書き直す

画面テスト

e2e/ · Playwright。同じくバイナリを起動してブラウザで操作し、結果を API で確かめる。そのまま使える

言語非依存の契約

  • 内部 API: api/openapi.yaml
  • Jira 互換: ゴールデン JSON
  • MCP: ツールの JSON Schema
  • DB: 素の SQL マイグレーション
  • CLI: serve / seed / token / backup / restore の入出力
