02 · 流れ

作る → 試す → 予定を見る → 取り込む

1 作る

下書き

マップのヘッダー「下書き」から。いまのマップの複製（既定）か空。キーは TAPPD1、番号はそのまま（TAPP-ST3 → TAPPD1-ST3）
2 試す

自由に

足す・消す・名前を変える・置き直す。元のプロジェクトは変わらない。AI も MCP で下書きを直せる
3 見る

取り込みの予定

増える・変わる・消える・戻す。両方で変わったものは衝突。元にしかないものは残る
4 入れる

一度に

人だけが、1 つのトランザクションで。下書きはそのまま使え、次は違いだけが入る
下書きはプロジェクト一覧・サイドバーには出ない。元のマップの「下書き」メニューから開く。いらなくなったら「下書きを捨てる」（アーカイブ）。
