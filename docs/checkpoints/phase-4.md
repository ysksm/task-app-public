# ✅ 確認ポイント 4（P4: 受入検査・マインドマップ・保存ビュー・ロードマップ）

## 起動方法

```bash
make build
make demo-fresh        # /tmp/taskapp-demo に新しいデモデータを作って起動（http://127.0.0.1:7700）
```

7700 番で前のサーバーが動いていたら止めてから起動してください。デモデータは今回の確認用に、受入基準・過去の差し戻し・保存ビューを追加しています。

## 確認していただきたい操作

### 1. 受入検査（サイドバー「受入検査」）

- **APP-2「ユーザーとしてログインしたい」** が受入待ち（2 回目）で並んでいます。1 回目は「エラーメッセージが英語のまま」で差し戻された履歴があります。
- 受入基準ごとに **OK / NG / 対象外** を選び、NG には理由を書きます。総評を書いて **差し戻し**（→ In Progress）または **合格**（→ Done）。
  - 差し戻しは総評（理由）が必須。NG があると合格は押せません。
  - APP-2 には未完了の子イシューと未回答 QA があるため、合格を押すと警告が出て「警告を承知で合格にする」に変わります。
- 判定するとアクティビティに「受入検査で差し戻した『…』」と残り、エージェントは MCP の `get_issue` で差し戻し理由と NG の基準を読めます。
- 受入基準は、ストーリー / フィーチャーの詳細画面の「受入基準」から追加・編集できます（APP-17 に 1 件あります）。

### 2. マインドマップ（プロジェクトのイシュー一覧 → 表示切替「マップ」）

- プロジェクト全体の階層が左から右へ広がります。ノードには種別の色、ステータス、進捗、担当（エージェントはオレンジの縁）、未回答 QA の数（ブロッキングは赤）。
- ノードをクリックすると右に詳細が開きます。ダブルクリックか右端の丸ボタンで子を折りたたみ / 展開。
- 左上の「全体表示」「表示する深さ 1 / 2 / 3 / すべて」、ヘッダーの「ルート」でエピック単位の表示。
- フィルタ（例: 担当 = エージェント、完了を隠す）を付けると、該当しないノードが薄くなります。

### 3. ロードマップ（表示切替「ロードマップ」）

- エピックごとにストーリーを並べ、ステータスと進捗バー（子孫の完了数）、期日、担当を表示します。

### 4. 保存ビュー

- フィルタバー右端の「ビューを保存」で、フィルタと表示（リスト / ボード / マップなど・グループ・並び・マップのルート）を名前付きで保存。サイドバー「ビュー」に並びます。
- ビューを開いて条件を変えると「ビューを更新」が出ます。「…」から名前変更・削除。
- デモには「エージェントの作業中」（ボード）と「全体マップ（未完了）」（マップ）があります。
- マイタスクなど、画面自体に条件がある場所で保存したビューは、その条件（例: 担当 = 自分）も含めて保存されます。

### 5. プロジェクト設定（イシュー一覧のタイトル横の歯車）

- 名前・説明、階層スキップの許可。
- ステータスの追加・名前変更・色・並べ替え（同じカテゴリ内）・削除、新規イシューの既定と受入待ちに使うステータスの指定。
  - 使用中・既定・受入待ち・最後の完了 / 進行中のステータスは削除できません。
  - QA のステータスは回答の流れと連動しているため固定です。
- ラベルの追加・名前変更・色・削除。

## 確認済みのこと

- API テスト 152 件すべて成功（今回追加: 受入検査 7 件、保存ビュー・ステータス・ラベル 8 件）。OpenAPI の契約チェックも追加分を含めて成功。
- ブラウザで、受入検査の差し戻し・警告つき合格の流れ、マップ（ルート切替・フィルタで薄く表示・サイドピーク）、ロードマップ、ビューの保存と復元、プロジェクト設定を確認。

## 確認できていないこと・制限

- マップ上でドラッグして親を付け替える（MAP-06）と画像出力（MAP-07）は優先度 C のため未実装（P5）。
- エラーメッセージは API の文言（英語）のまま表示されます（例: 使用中のステータスを削除しようとしたとき）。
- ダークモードでのマップの見え方は未確認。
- サイドバーの「受入検査」の件数は、変更のたびに受入待ち一覧（子孫の未完了数の集計を含む）を取り直しています。デモ規模では問題ありませんが、P5 の性能確認（5-3）で見直します。

## 決めたこと

- 受入基準はストーリーとフィーチャーに設定。判定は人間のみ。
- マップとロードマップは別画面ではなくイシュー一覧の表示切替にしました（フィルタ・詳細パネルを共有するため）。URL は `/p/APP/issues?view=map`。
- 保存ビューは作成者だけが見られます（ローカル単独利用のため共有機能は付けていません）。
- マップには QA をノードとして出さず、バッジで示します。

## 確認したいこと

1. マインドマップのレイアウトと情報量（ノードの中身、既定で全部展開、QA をバッジにしたこと）

3. 保存ビュー・ロードマップ・プロジェクト設定で足りないもの
4. 次は P5（コマンドパレット、エクスポート / インポート、性能確認、配布）に進めてよいか
