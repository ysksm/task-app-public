## DB と API

- マイグレーション 011 で `projects.requirements_mode`（`structured` | `quick`）。列の既定は `structured` なので、**前からあるプロジェクトは M1 の画面のまま**。`CreateProject` は指定がなければ `quick` にする。
- `Project`・`CreateProjectInput`・`UpdateProjectInput` に `requirements_mode`。それ以外の値は 400 `invalid_argument`。
- `StoryMap` に `mode`。REST の `GET /projects/{key}/storymap` も MCP の `get_storymap` も返す。
- ストーリーと条件の API の決まりはモードで変えない。`structured` のプロジェクトでもタイトルだけ・1 行の条件は受け付け、手順のないものは「抜け」に出る。

## 画面

| | まず書く（quick） | 整理して書く（structured） |
|---|---|---|
| S15 | 案 D のまま（ひとこと入力・未整理の列・抜けは数だけ） | 案 A の形。ひとこと入力と未整理の列はなし。手順のないストーリーはマップの上に「⚠ 未整理 N件」。抜けは警告の色。ペルソナの絞り込みはいつも出る |
| S16 | 案 D のまま | したいこと・そうすれば・ペルソナがいつも出る。条件はいつも 3 欄。本文は書いてあるときだけ出す。手順がなければ「手順が未設定（抜け）」 |

マップのヘッダーに今のモードを出し、押すとプロジェクト設定へ移る。

## わかっている制限

- モードはプロジェクト単位。人ごとに見え方を変える切り替えはない。
- 整理して書くプロジェクトでも、API や MCP からはタイトルだけのストーリーを作れる（抜けとして出る）。受け付けないようにはしていない。
- 「前提・操作が空の条件」は抜けの一覧には入れていない（S16 で「—」と見えるだけ）。
