# ✅ 確認: プロジェクトのティアと操作の左寄せ（追加作業 A-9）

「重要なプロジェクトとそうでないものを分けてボードを見たい」「操作系は左に寄せてほしい」という要望への対応です。ブランチは `feat/project-tier` です。

## 入れたもの

| 項目 | 内容 |
|---|---|
| プロジェクトのティア | **★ 注力**（いま力を入れているもの）/ **通常**（ときどき進めるもの）/ **🌱 その他**（優先度は低め・気軽に始めてみたもの）。既定は通常。`projects.tier`（マイグレーション 008） |
| 全体ボード | 行をティアの段（注力 → 通常 → その他）に分ける。「その他」の行は最初からたたみ、件数だけ出す。行の見出しの印からティアを変えられる |
| 「注力のみ」 | フィルタバーのチェック。注力のプロジェクトだけにする（URL・保存ビューに残る）。フィルタの「プロジェクトのティア」で通常・その他も選べる。マイタスクでも使える |
| プロジェクト一覧・サイドバー | ティアごとに分けて並べる。カードの印から変えられる。サイドバーは注力に ★、「その他」は薄く |
| プロジェクト設定 | 基本情報に「ティア」 |
| API | プロジェクトの作成・更新・一覧に `tier`。フィルタ項目 `project_tier`。MCP の `list_projects` にも `tier` が出る |
| 操作の左寄せ | 一覧系のヘッダー（マイタスク、全体ボード、プロジェクトのイシュー、保存ビュー）で、新規・表示の切り替え・プロジェクトで分けるをタイトルのすぐ右へ移した。フィルタバーのグループ・並び・ビューを保存も、右端から「完了を隠す」の続きへ。QA インボックス・エージェント活動・プロジェクト一覧のヘッダーも左寄せ |

## 確認済みのこと

- Go の単体テスト、API テスト 189 件（+2 件）、画面テスト 34 件（+1 件）がすべて成功した。
- 画面を撮って、全体ボード・プロジェクト一覧・マイタスク・プロジェクト設定の見た目を確かめた。

## 確認したいこと

1. 名前は、最初の「サイド」から、オーナーの指定で「その他」に変えた（「サイドバー」などとかぶるため）。内部の値は `side` のまま。
2. ティアは全員共通の設定にしています（プロジェクトに 1 つ）。人ごとに変えたくなったら言ってください。
3. 「その他」の行を開いても、画面を離れるとたたんだ状態に戻ります。開いたままにしたいですか。
4. 本番の 6 プロジェクトのティアは、マージ後に設定します。案は **注力**: TAPP・INFRA・APPDEV、**通常**: OTEL・SLD、**その他**: SEC です。
