# ✅ 確認: 複数端末からの利用（追加作業 A-3）

ご要望の案 1・2・4 を実装しました。ログインは **パスワード**、ログインの有効期間は **サーバーが動いている間だけ** です（ご回答どおり）。ブランチは `feat/multi-device` です。

> 訂正: 前回「MCP は stdio だけ」とお伝えしましたが、MCP の HTTP 提供（`/mcp`、トークン認証）は P3 で実装済みでした。案 2 は、ほかの端末からつながることの確認と、設定画面・ガイドへの案内の追加だけです。

## 起動

```bash
make build
./bin/taskapp seed --preset demo --data /tmp/taskapp-md
./bin/taskapp serve --data /tmp/taskapp-md --host 0.0.0.0 --port 7701   # 7700 の既存サーバーとぶつからないように
```

起動時に、暗号化されないことと、まだ誰もパスワードを持っていないことの警告が出ます。

## 確認していただきたい操作

### 1. この PC で

- <http://127.0.0.1:7701> は今までどおりログインなしで入れること。
- 設定 › アカウント でオーナーのパスワードを設定できること（8 文字以上、2 回入力）。
- 設定 › メンバーとエージェント で、Alice の「パスワードを設定」からほかの人のパスワードを設定できること。
- 設定 › ほかの端末から使う に、LAN の URL（例: `http://192.168.x.x:7701`）が出ること。
- サイドバー下のログアウトを押すとログイン画面になり、再読み込みしても自動では入らないこと。「このPCのオーナーとして入る」で戻れること。

### 2. ほかの端末（スマホ・別の PC）で

- 上の URL を開くとログイン画面になること（「このPCのオーナーとして入る」は出ない）。
- パスワードでログインでき、開こうとした画面に戻ること。
- Alice でログインした場合、設定にデータ（バックアップ・エクスポート）やエージェントの追加が出ないこと。
- 5 回続けて間違えると、1 分間ログインできないこと。

### 3. 別の PC のエージェント（MCP）

設定 › エージェントの接続（MCP）の「HTTP（ほかの端末のエージェント）」のコマンドを別の PC で実行し、Claude Code から `list_my_issues` などが使えること。

### 4. コマンド

```bash
./bin/taskapp passwd --data /tmp/taskapp-md --user alice     # 2 回入力。サーバーが動いたままでもすぐ効く
./bin/taskapp passwd --data /tmp/taskapp-md --user alice --clear
```

## 確認済みのこと

- 単体テスト（この PC かどうかの判定、パスワードのハッシュ形式と、Python で作ったハッシュの検証）、API テスト 176 件（うちログイン 12 件）、画面テスト 27 件（うちログイン 7 件）がすべて成功。
- 手で確認（`--host 0.0.0.0`、この Mac の LAN の IP に curl とブラウザで接続）:
  - LAN の IP からの自動ログインは 403、`127.0.0.1` からは成功。
  - LAN の IP からパスワードでログインできる。
  - LAN の IP から MCP（`/mcp`）の initialize が通る。
  - 設定画面に `remote_url` が出る。
  - `serve.json` は `127.0.0.1:<port>` になり、`restore` が起動中を正しく検出する。
- パスワードのハッシュは API の応答にもエクスポートにも出ない（`has_password` だけ返す）。
- 自動ログインは、接続元と `Host` ヘッダーの両方がループバックのときだけ。DNS リバインディングや、この PC 上のリバースプロキシ（`tailscale serve` など）からはログイン画面になる。

## 確認できていないこと・制限

- 実機のスマホ・別の PC からは試していません。この Mac 自身の LAN の IP から接続して確認しました。
- **画面はスマホの幅に合わせていません。** ログイン画面はスマホでも使えますが、ほかの画面は PC 向けのレイアウト（左にサイドバー）のままで、スマホでは横にはみ出します。
- 通信は HTTP のままです。LAN か VPN（Tailscale など）の中で使う前提です。Cookie に `Secure` 属性は付けていません（HTTPS ではないため）。
- `tailscale serve` のようにこの PC 上のプロキシを経由すると、MCP（HTTP）は SDK の DNS リバインディング対策で 403 になる見込みです（SDK のコードから判断。未確認）。Tailscale では、IP（`100.x.y.z`）か MagicDNS の名前で直接つないでください。
- ログインはサーバーを再起動すると切れます（ご指定どおり）。
- エクスポートにはパスワードが含まれないため、`import` で移したあとは設定し直しが必要です（バックアップ・復元では残ります）。
- Windows では確認していません。
