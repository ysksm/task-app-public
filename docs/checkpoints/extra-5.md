# ✅ 確認: 全体ボード（追加作業 A-6）

全プロジェクトのイシューを、1 枚のボードで見られるようにしました。作り方はオーナーに選んでいただきました。列はステータスの分類、行はプロジェクトです。入口はサイドバーです。ブランチは `feat/all-board` です。

## 入れたもの

| 項目 | 内容 |
|---|---|
| 画面 S14 全体ボード（`/board`） | サイドバー「全体ボード」、`G` → `B`、コマンドパレットから開く。リストの表示にも切り替えられる |
| 列 | ステータスの分類 5 つ（Backlog・未着手・進行中・完了・キャンセル）。ステータスはプロジェクトごとに違うため、全プロジェクトに共通の分類で列を作る。カードには、そのプロジェクトでのステータス名を出す |
| 行 | プロジェクトごとに分ける。見出しをクリックするとたたむ。「プロジェクトで分ける」を外すと行がなくなる（URL に `lanes=none`） |
| ドラッグ | カードを別の列へ移すと、そのプロジェクトの、その分類の最初のステータスになる。QA は QA 用のステータスへ、ほかは QA 用以外へ。別のプロジェクトの行へは動かない |
| プロジェクトごとの件数 | 行ごとの各列の上に、そのプロジェクトのその分類の件数を出す。分類の中にステータスが複数あれば内訳も出す（例: `◑ 6（受入待ち 1・In Progress 5）`）。たたんだ行にも件数だけ出す（オーナーの要望） |
| 完了を隠す | フィルタの「完了を隠す」をオンにすると、完了とキャンセルの列ごと消える（オーナーの要望）。プロジェクトのボードも同じにした |
| ついでに直したもの | プロジェクトを指定しない保存ビューをボード表示にすると、これまでは列が出なかった。全体ボードと同じ形で出るようにした |

サーバーの変更はありません。ステータスは、プロジェクトごとの既存の API から読みます。

## 確認済みのこと

- 画面テスト 31 件（全体ボードの 3 件を含む）がすべて成功した。全体を何度か続けて実行し、どれも成功した。
  - プロジェクトを足すと、そのプロジェクトの行ができる。
  - 「未着手」のカードを「進行中」へドラッグすると、API で見ても進行中になる。
  - 行を分けない表示に切り替えられる。
  - `G` → `B` で開ける。
  - 「完了を隠す」で、全体ボードとプロジェクトのボードの完了・キャンセルの列が消える。
- 一度だけ、ドラッグの直後に「プロジェクトで分ける」のクリックが反映されないことがあった。その後、そのテストを 16 回と全体を 3 回実行したが、再現しなかった。原因はわかっていない。いまのテストは、クリックしたあとに URL が変わるのを待つようにしている。

1. 「完了」と「キャンセル」の列は最初から出し、「完了を隠す」で列ごと消すようにした（回答済み）。
