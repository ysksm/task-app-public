# ✅ 確認: どこまで使えるか（利用状況と上限、追加作業 A-8）

「この構成でどれぐらいの規模まで使えるか」「想定容量の到達率を確かめたい」という要望への対応です。ブランチは `feat/capacity` です。

## 規模の目安（2026-10-12 に測定）

| 項目 | 値 | 根拠 |
|---|---|---|
| イシュー | **1 万件までは確かめ済み**。一覧 0.06 秒、フィルタ 0.02 秒 | P5 の性能確認（10,240 件）。目標は 0.3 秒以内 |
| 全体ボード・一覧に一度に出せる数 | **2,000 件**（画面の読み込み上限） | 2,000 件の読み込みは 0.07 秒（1.9 MB）。超えると先頭 2,000 件だけになる |
| マインドマップ | 1 プロジェクト **1,000 ノード** | NFR-03 |
| データベースの大きさ | 1 万件で **約 9 MB** | 測定 |
| メモリ | 1 万件で **約 60 MB**（今は約 11 MB） | 測定 |

いちばん先に当たるのは、**全体ボード・一覧の 2,000 件**です。完了したイシューも数に入るので、何もしないと、使い続けるうちに超えます。超えても「完了を隠す」で未完了だけにすれば出せます。ディスクとメモリは、何十万件になっても足ります。

## 入れたもの

| 項目 | 内容 |
|---|---|
| 設定 › 利用状況と上限（オーナーのみ） | 次の 4 つについて、到達率をバーと % で出す。70% で黄色、90% で赤 |
| | ・イシュー（全体）/ 1 万件 |
| | ・全体ボード・一覧に一度に出せる数 / 2,000 件 |
| | ・最大のプロジェクト / 1,000 ノード |
| | ・ディスク（taskapp のデータ、データベース、バックアップの内訳つき） |
| | そのほかに、プロジェクト数・メンバー数・履歴の件数・メモリも出す |
| `GET /api/v1/capacity` | 件数・大きさ・ディスク・メモリを返す（オーナーのみ）。上限の数字は画面側に持つ |
| 読み込み上限のお知らせ | 一覧・ボードで、上限を超えて一部しか出ていないときに「全 N 件のうち、先頭 2,000 件だけを表示しています」と出す。これまでは何も出ず、気づけなかった |

## 確認済みのこと

- API テスト 187 件（+2 件）と画面テスト 33 件（+1 件）が、すべて成功した。
  - 件数が正しい。イシューを足すと増え、消すと戻る。
  - オーナー以外には 403、ログインしていなければ 401 になる。
- 1 万件のデータで画面を開いて確かめた。
  - 到達率が 102%・512%・256% になり、赤で出る。
  - 全体ボードの上に、読み込み上限のお知らせが出る。
- Windows 向けのビルドが通る（ディスクの空きは「取得できません」と出る）。

## 確認したいこと

1. 2,000 件の上限は、そのままにしています。上げると表示が重くなります。たとえば 5,000 件にすると、読み込みが 0.15 秒・4.8 MB になり、カードの描画も増えます。今の使い方では、未完了が 2,000 件に近づいてから考えればよいと思いますが、どうしますか。
2. ほかに見たい項目（例: 添付ファイルの大きさ、エージェントの数）はありますか。
