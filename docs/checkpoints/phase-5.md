# ✅ 確認ポイント 5（P5: 仕上げ・配布）

P4 は確認ポイント 4 の指摘（未完了の子イシューの確認方法）を反映して main にマージ済みです（PR #2）。P5 はそのあとのブランチ `feat/p5` です。

## 配布物から起動する

```bash
make dist                                   # dist/ に 6 プラットフォームのアーカイブ
tar -xzf dist/taskapp_*_darwin_arm64.tar.gz -C /tmp
/tmp/taskapp_*_darwin_arm64/taskapp seed --preset demo --data /tmp/taskapp-p5
/tmp/taskapp_*_darwin_arm64/taskapp serve --data /tmp/taskapp-p5     # http://127.0.0.1:7700
```

7700 番で前のサーバーが動いていたら止めてください。手順の全体は [利用ガイド](../06-guide.md)（スライド: `docs/slides/guide.html`）にまとめました。

## 確認していただきたい操作

### 1. コマンドパレットとショートカット

- `⌘K`（またはサイドバー上部の「検索・移動」）でパレットを開き、画面名・プロジェクト名・ビュー名・イシューのキーやタイトルで探して Enter。
- `G` → `M`（マイタスク）/ `Q`（QA）/ `A`（受入検査）/ `E`（エージェント活動）/ `P`（プロジェクト）/ `S`（設定）。`?` でショートカット一覧。

### 2. バックアップとエクスポート

- 設定 › データ の「JSON をエクスポート」でファイルを保存。
- そのファイルを新しいディレクトリに取り込んで起動すると、同じ状態に戻ります（トークンもそのまま使えます）。

  ```bash
  taskapp import --data /tmp/taskapp-restored --in taskapp-export-*.json
  taskapp serve --data /tmp/taskapp-restored --port 7701
  ```

- `taskapp backup --data /tmp/taskapp-p5 --out /tmp/backup.db` は起動したままで取れます。

### 3. マインドマップの付け替えと画像出力

- マップでノードをドラッグして別のノードに重ねると（重ねた先が緑で強調）、親が付け替わります。プロジェクトのノードに重ねると最上位に移ります。階層の規則に合わない移動（ストーリーをタスクの下へ等）は理由が表示されて元に戻ります。
- 左上の「PNG」で、表示中の階層を画像として保存します。

### 4. 性能（任意）

```bash
make perf        # 約 1 万件のデータを作って主要な問い合わせを計測（30 秒ほど）
```

## 確認済みのこと

- API テスト 158 件すべて成功（今回追加: エクスポート / インポート 6 件）。
- 性能（10,240 件、中央値）: 一覧 60ms、フィルタ 16〜23ms、エピック配下 15ms（改善前 665ms）、受入待ち一覧 65ms（改善前 4.6 秒）、Jira 検索 39ms。目標の 300ms 以内。詳細は [05 実装計画](../05-implementation-plan.md) の P5 の表。
- マップ: 2,560 ノードのプロジェクトはストーリーまで折りたたんで開き、すべて展開しても約 0.4 秒、ズーム中は 1 フレーム約 17ms。
- ブラウザで、パレット（検索・Enter で移動）、`G` → `A`、`?`、マップのドラッグ付け替え（成功・規則違反のエラー）、PNG 出力（256 ノードのエピックを全展開して全ノードが入ること）、設定画面からのエクスポート（1 万件で 200 OK）を確認。
- `make dist` で 6 プラットフォームのアーカイブを作成し、macOS（arm64）版を展開して起動できることを確認。

## 確認できていないこと・制限

- Windows / Linux 版は作成のみで、実機での起動は未確認。
- 添付ファイル（ISS-08）は見送りました（保存先、アップロード画面、Jira の添付 API が必要なため）。
- `J` / `K` での行移動、`S` / `A` でのステータス・担当変更のショートカットは入れていません。
- エクスポートは API トークンのハッシュを含みます。外部に渡すときは注意が必要です。
- サイドバーのボタンは OS にかかわらず `⌘K` と表示しています（Windows / Linux では `Ctrl+K`）。
- `make perf` には `python3` と `bc` が必要です。
- GoReleaser の設定は用意しましたが、GoReleaser 自体では実行していません（`make dist` で同じ構成のアーカイブを作成）。
